# pj_kobe2030

[kobe2030](https://github.com/tyra0119/kobe2030)（神戸2030ビジョン × 公共交通オープンデータ）の公開用。`scripts/publish.js` の出力だけを置く。

いまは「車なしで暮らせる度マップ（神戸市北区・三田市）」: 人口のある 250m メッシュごとに、バス停・駅、スーパー、病院・診療所、小学校まで歩いて何分かを、坂も考えて色分けする。バスの本数・終バスはまだ入っていない。

公開ページ: https://tyra0119.github.io/pj_kobe2030/

出典: 国土数値情報（バス停留所・鉄道・医療機関・学校・人口集中地区・行政区域。国土交通省）、2020年国勢調査 250mメッシュ（総務省統計局 e-Stat）、地理院タイル（標高・淡色地図）、© OpenStreetMap contributors（ODbL）、神戸市 GTFS（gtfs-data.jp, CC BY 2.1 JP / CC BY 4.0）を加工して作成
